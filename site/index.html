03

Three-minute setup

Download. Connect. Listen.

  1. 1

    Download your ZIP

    Choose macOS or Windows. The runtime is already included.

  2. 2

    Run the installer

    Paste the public Discord Application ID once. No token or secret is used.

  3. 3

    Press play

    Keep Apple Music and desktop Discord open. The rest happens locally.

◉
