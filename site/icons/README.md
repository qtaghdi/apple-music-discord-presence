# Brand icons

The Apple and Windows SVG paths in this directory come from [Bootstrap Icons](https://github.com/twbs/icons), licensed under the MIT License. The marks are used only to identify the supported operating systems.

`apple-music.svg` is the Apple Music app icon authored by Apple Inc. and sourced from the [Wikimedia Commons copy](https://commons.wikimedia.org/wiki/File:Apple_Music_Icon.svg) of Apple's original asset. It is used only to identify the Apple Music service.
