# Apple Music Discord Presence v0.4.2

This release changes playback time from a remaining countdown to elapsed progress from the beginning of the song.

## Highlights

- Discord now counts up from the current playback position instead of counting down to the end.
- The settings preview shows both current and total time, such as `1:19 / 2:18`.
- The Playback progress switch hides the complete progress treatment when disabled.

## What changed

### Improved

- Presence timestamps now contain a start value only, which Discord renders as elapsed time.
- Settings and website preview copy now describe playback progress rather than time remaining.

### Fixed

- Disabling Playback progress hides the progress bar and time label together.
- Automated coverage now verifies that no end timestamp is sent.

## Verification

- macOS Swift compilation, TypeScript compilation, and all twenty automated tests passed locally.
- The progress switch, progress bar, timer label, and save flow were checked in the in-app browser.
- The updated screen was visually checked at 1440 × 1000.
- Windows TypeScript, tests, packaging, and PowerShell syntax are verified by CI.

## Known limitations

- Discord Rich Presence supports a start-based elapsed counter or an end-based countdown, but not custom `current / total` timer text. The exact `current / total` format therefore appears in the local preview; Discord itself shows the elapsed counter.
- First installation still needs a public Discord Application ID.
- Music-to-Discord behavior still requires manual verification in signed-in desktop apps.
- The macOS ZIP is unsigned and not notarized; first launch may require **Right-click → Open**.

## Upgrade notes

Replace the previous extracted folder and rerun the installer. Existing configuration values are preserved.
