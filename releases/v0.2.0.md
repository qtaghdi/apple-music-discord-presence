# Apple Music Discord Presence v0.2.0

Apple Music Discord Presence now supports both macOS and Windows, with ready-to-download ZIP packages and a new product website.

## Highlights

- Added Windows 10/11 support using the native Windows system media session.
- Added self-contained downloads that do not require users to install Node.js or developer tools.
- Added a public [product website](https://qtaghdi.github.io/apple-music-discord-presence/) with platform-aware download buttons.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | [`apple-music-discord-presence-macos-arm64.zip`](https://github.com/qtaghdi/apple-music-discord-presence/releases/download/v0.2.0/apple-music-discord-presence-macos-arm64.zip) | Apple Silicon, macOS 13+ |
| Windows | [`apple-music-discord-presence-windows-x64.zip`](https://github.com/qtaghdi/apple-music-discord-presence/releases/download/v0.2.0/apple-music-discord-presence-windows-x64.zip) | Windows 10 1809+ or Windows 11, x64 |

Extract the ZIP, keep the folder somewhere permanent, and run `Install.command` on macOS or `Install.cmd` on Windows.

## What changed

### Added

- Apple Music metadata collection through Windows Global System Media Transport Controls.
- Discord IPC over Windows named pipes.
- Login-startup installers and uninstallers for macOS and Windows.
- Automated dual-platform ZIP packaging and GitHub Releases publishing.
- GitHub Pages deployment and promotional landing page.

### Improved

- Cross-platform configuration discovery.
- Portable path handling and test coverage across macOS and Windows.
- Release downloads now include a private Node.js runtime.

### Fixed

- Corrected the source-installation start command to point to the compiled entry file.
- Made platform-path tests deterministic on both operating systems.

## Verification

- macOS Apple Silicon Swift helper build passed.
- TypeScript strict compilation passed on macOS and Windows.
- All nine automated tests passed on both platforms.
- PowerShell scripts passed Windows syntax validation.
- GitHub Pages deployment and download CTA layout were visually verified.

## Known limitations

- Installation currently asks for a Discord Application ID until a shared project ID is embedded.
- Windows Music-to-Discord behavior still needs a manual test in an interactive Windows session with both apps signed in.
- The macOS ZIP is unsigned and not notarized; first launch may require **Right-click → Open**.

## Upgrade notes

Existing macOS source installations do not require a configuration migration. ZIP users should replace the previous extracted folder and rerun the installer.
