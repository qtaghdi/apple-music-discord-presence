# Apple Music Discord Presence v0.5.0

Released October 23, 2026.

> Open settings from your menu bar or system tray, with better album covers and playback progress in Discord.

## Highlights

- macOS music-note menu bar app and Windows tray app: settings, connection status, reconnect, launch at login, logs, and quit.
- Improved cover matching across regions and Korean/English metadata.
- Discord progress bars and Artist - Track status text, without an extra emoji.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Extract the ZIP and run `Install.command` on macOS or `Install.cmd` on Windows. macOS installs into `~/Applications`; Windows creates a Start menu shortcut and requires keeping the extracted folder in place. Node.js is bundled.

## What changed

### Added

- Native first-run Application ID dialog on macOS, with a developer portal link.
- Settings favicon and connection status reporting for the desktop menus.

### Improved

- Cover lookup tries the configured country and US catalog, handles translated titles and collaborators, and uses exact album matches when needed.
- Album-only matches never link to an unrelated track.
- New installations hide activity when playback is paused. This can be changed in Settings.

### Fixed

- Both timestamp endpoints are provided for Discord listening progress bars.
- The macOS app declares Music automation usage and entitlement instead of launching hardened Node directly as a login agent.
- The desktop app owns and stops its worker on Quit.

## Verification

- Required local verification: Swift helper and menu bar build, strict TypeScript compilation, unit tests.
- Both macOS and Windows CI must pass before this release is tagged, including packaging and Windows PowerShell syntax.
- Local macOS checks: Discord connection, Music metadata, settings updates, and catalog artwork responses.

## Known limitations

- Windows desktop interaction and signed-in Music-to-Discord behavior still require manual testing; CI is not an interactive end-to-end test.
- The macOS app is ad-hoc signed, not notarized; first launch may need approval in Privacy & Security, plus Music automation permission.
- Discord hides Rich Presence buttons on your own profile. Other users can see the Apple Music button when a song link is found.
- Some local or region-specific tracks may have no matching artwork. Text presence continues.
- A public Discord Application ID is still required once; no Discord login, bot token, or client secret is needed.

## Upgrade notes

Quit the existing client before installing. Source users should also stop their previous LaunchAgent. Existing configuration is preserved, including the paused-display preference; turn off **Show paused** if you want activity cleared on pause. Launch at login is controlled separately from Quit in the icon menu.
