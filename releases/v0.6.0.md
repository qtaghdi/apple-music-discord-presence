# Apple Music Discord Presence v0.6.0

> Download, install, and play — no Discord developer setup required.

Released October 24, 2026.

## Highlights

- The public shared Discord application is ready to use, so new users no longer need an Application ID or developer account.
- Existing custom IDs and configuration remain supported.
- Real Discord activity screenshot, clearer setup instructions, and optional GitHub star links.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Quit the existing app, extract the ZIP, then run `Install.command` on macOS or `Install.cmd` on Windows. macOS installs into `~/Applications`; Windows users must keep the extracted folder in place. Allow Music automation when macOS asks.

## What changed

### Improved

- Removed the macOS first-run ID dialog and Windows ID prompt.
- The runtime falls back to the shared public application only when no custom ID is configured; malformed overrides are still reported.
- Added a real Discord screenshot and direct download links at the top of the README.
- Updated landing-page setup instructions, website social image, and optional Star on GitHub links in the landing and local settings screen.

## Verification

- Required local verification includes Swift helper/menu bar compilation, strict TypeScript checks, and unit tests.
- macOS and Windows CI verify builds, tests, packaging, and PowerShell syntax before tagging.
- Tests cover shared defaults, existing custom IDs, environment overrides, and malformed IDs.

## Known limitations

- The macOS app is ad-hoc signed, not notarized; first launch may require approval in Privacy & Security and Music automation permission.
- Windows interactive playback still requires manual testing; CI is not a signed-in desktop end-to-end test.
- Discord hides Rich Presence buttons when viewing your own profile.
- Some local or region-specific tracks may not have matching artwork; text presence continues.

## Upgrade notes

No configuration migration is needed. Existing custom Application IDs and display settings are preserved. To switch an existing installation to the shared app, remove only `discordClientId` from its config and unset `DISCORD_CLIENT_ID`, then reconnect.
