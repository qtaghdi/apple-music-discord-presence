# Apple Music Discord Presence v0.7.0

> 한국어로 설치 안내를 읽고, 랜딩과 설정 화면을 이용하세요.

Released October 24, 2026.

## Highlights

- Complete Korean README, landing page, and local settings interface.
- 한국어 / English selector, browser-language detection, remembered preferences, and direct `?lang=ko` / `?lang=en` links.
- Switching languages preserves unsaved display options and original track metadata.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Quit the existing app, extract the ZIP, and run `Install.command` on macOS or `Install.cmd` on Windows. No Application ID setup is required. Allow Music automation on macOS when prompted.

## What changed

### Added

- [한국어 README](https://github.com/qtaghdi/apple-music-discord-presence/blob/main/README.ko.md) covering setup, configuration, permissions, troubleshooting, privacy, and development.
- Korean labels, accessibility text, save/load messages, and release labels across both web interfaces.
- Language selection remains usable when browser storage is blocked.

### Improved

- Korean typography and compact navigation for small screens.
- Settings explain that keeping activity visible while paused also keeps the listening activity visible.
- Versioned scripts avoid showing cached English-only UI after an upgrade.

## Verification

- Local `npm run verify`: Swift builds, strict TypeScript compilation, and unit tests.
- macOS/Windows CI verify builds, tests, packaging, signing, and PowerShell syntax before tagging.
- Browser checks cover Korean/English switching, unsaved checkbox preservation, and Korean save feedback.

## Known limitations

- Browser language preferences are stored separately for the public website and the local settings origin.
- Track titles, artist names, and album names retain Music metadata; they are not translated.
- Native desktop menus and installer messages retain their existing language; this release localizes the web interfaces and documentation.
- macOS still requires Music automation permission and may require first-launch approval for the ad-hoc-signed app. Interactive Windows playback requires manual testing.

## Upgrade notes

Existing configuration is preserved. Reopen settings after upgrading. Choose 한국어 in the header or visit `http://127.0.0.1:47621/?lang=ko`. Language changes never save or change playback display options on their own.
