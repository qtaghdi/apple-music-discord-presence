# Apple Music Discord Presence v0.4.3

The public website now carries the same quiet, painterly atmosphere as the local settings screen from the first viewport through the final download.

## Highlights

- A complete landing-page redesign using deep blue, periwinkle, lavender, and dusty-pink color fields.
- Responsive layouts and restrained motion across the product preview, features, downloads, setup, and closing CTA.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Extract the ZIP, keep the folder somewhere permanent, and run `Install.command` on macOS or `Install.cmd` on Windows.

## What changed

### Improved

- Unified the landing page and local settings screen around one visual language and shared original artwork.
- Refined desktop and mobile spacing, platform cards, installation steps, hover feedback, and section transitions.
- Preserved authentic Apple and Windows icons and the existing download flow.

## Verification

- macOS CI: build, Swift helper, TypeScript, and tests.
- Windows CI: TypeScript, tests, and PowerShell syntax.
- Manual Browser/IAB checks at 1440 × 1000 and 390 × 844.
- Verified hero, feature flow, platform downloads, setup sequence, final CTA, reduced-motion behavior, and browser console output.

## Known limitations

- The macOS build is not signed or notarized, so the first launch may require **Right-click → Open**.
- End-to-end playback still requires Apple Music and desktop Discord running on the user's computer.

## Upgrade notes

No migration required.
