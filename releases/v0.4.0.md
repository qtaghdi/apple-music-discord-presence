# Apple Music Discord Presence v0.4.0

This release replaces manual display configuration with a private settings screen that updates Discord immediately.

## Highlights

- Open a polished local settings screen from the included macOS or Windows launcher.
- See a live Discord preview while choosing album, artwork, timer, button, pause, and detail-order options.
- Save changes without restarting the background app.

Extract the ZIP, keep the folder somewhere permanent, and run `Install.command` on macOS or `Install.cmd` on Windows. After installation, open `Settings.command` or `Settings.cmd` to customize the activity.

## What changed

### Added

- A responsive local settings screen with a live Discord activity preview.
- One-click settings launchers for macOS and Windows packages.
- Tests for same-origin settings access, settings validation, and preservation of advanced configuration.

### Improved

- Display changes now update the running activity immediately.
- The local service binds only to `127.0.0.1` and rejects cross-origin updates.
- Existing Application ID, polling, region, and fallback-artwork settings are preserved.

## Verification

- macOS TypeScript compilation and all nineteen automated tests passed locally.
- The settings screen was checked in the in-app browser at desktop and 390 × 844 mobile sizes.
- Toggle, detail-order, preview, and save behavior were exercised against the local settings API.
- Windows TypeScript, tests, packaging, and PowerShell syntax are verified by CI.

## Known limitations

- First installation still needs a public Discord Application ID.
- Music-to-Discord behavior still requires manual verification in signed-in desktop apps.
- The macOS ZIP is unsigned and not notarized; first launch may require **Right-click → Open**.

## Upgrade notes

Replace the previous extracted folder and rerun the installer. Existing `config.json` values are preserved. The new settings launcher is included in the replacement folder.
