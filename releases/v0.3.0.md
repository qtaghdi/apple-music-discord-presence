# Apple Music Discord Presence v0.3.0

This release adds practical controls for choosing exactly what appears in Discord Rich Presence.

## Highlights

- Show or hide album details, artwork, time remaining, paused tracks, and the Apple Music button.
- Choose between `Artist · Album` and `Album · Artist` ordering.
- Apply configuration changes with the included one-click restart helper.

## What changed

### Added

- Presence options for album names, timestamps, the Apple Music button, paused playback, and metadata ordering.
- Album artwork can be hidden independently from the Apple Music catalog button.
- `Restart.command` on macOS and `Restart.cmd` on Windows apply edited settings without signing out.
- Tests for legacy configuration defaults, custom settings, invalid display order, and presence combinations.

### Improved

- Existing configuration files are preserved when users rerun an installer to upgrade.
- Configuration documentation now lists every supported display option and its effect.
- The website now advertises the available display settings.

## Verification

- macOS build, Swift helper compilation, TypeScript strict compilation, and all sixteen tests passed.
- Windows TypeScript, tests, and PowerShell syntax are verified by CI.
- Apple and Windows site layouts were visually checked at desktop and intermediate widths.

## Known limitations

- First installation still needs a public Discord Application ID.
- Settings use `config.json`; there is no graphical settings window yet.
- Music-to-Discord behavior still requires manual verification in signed-in desktop apps.
- The macOS ZIP is unsigned and not notarized; first launch may require **Right-click → Open**.

## Upgrade notes

Replace the previous extracted folder and rerun the installer. Existing `config.json` settings are preserved, and missing v0.3 options use the defaults shown in `config.example.json`.
