# Apple Music Discord Presence v0.8.0

> Windows now uses a native app icon, and English and Korean landing pages are easier for search engines to discover.

## Highlights

- Fix the Windows tray and installed shortcut icons with a multi-size ICO asset.
- Add a crawlable Korean landing page, language-specific canonical URLs, a sitemap, and software metadata.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Extract the complete ZIP, keep the folder somewhere permanent, and run `Install.command` on macOS or `Install.cmd` on Windows.

## What changed

### Added

- Static Korean landing page with reciprocal language links and a sitemap.
- Google site verification and an IndexNow submission tool for maintainers.
- Windows package checks that decode the shipped icon and create a shortcut in a folder containing spaces.

### Fixed

- Windows tray and shortcuts now load the native ICO file instead of relying on unsupported image formats.
- The Windows installer validates extracted package files and gives a clearer error for incomplete downloads.

## Verification

- macOS: Swift helper, menu bar app, strict TypeScript compilation, and 38 tests.
- Windows CI: TypeScript, tests, PowerShell syntax, packaging, icon decoding, and shortcut persistence.
- Browser check: Korean landing page renders and switching to English opens the correct static page.

## Known limitations

- Windows Explorer and tray appearance still require a manual check on a Windows desktop.
- Search-engine submission does not guarantee indexing time or search ranking.

## Upgrade notes

- Existing configuration is preserved. Windows users should extract the complete new ZIP into a permanent folder and rerun `Install.cmd` to refresh their shortcuts.
