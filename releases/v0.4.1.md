# Apple Music Discord Presence v0.4.1

This release gives the local settings screen a quieter, more expressive visual identity and adds motion throughout the interface.

## Highlights

- A painterly blue, lavender, and dusty-pink theme inspired by the feeling of listening alone on an overcast afternoon.
- More tactile hover behavior for settings, buttons, artwork, and the Discord preview.
- Slow ambient color movement without literal rain effects or distracting animation.

## What changed

### Added

- Original abstract background and preview artwork with matte painted texture.
- Slow background drift, breathing status lights, floating artwork, progress shimmer, button sweeps, row hover movement, and pointer-responsive preview depth.
- A reduced-motion mode that respects the operating system preference.

### Improved

- Desktop composition now keeps settings and the Discord preview balanced in one view.
- Mobile controls remain readable and vertically stacked at narrow widths.
- Generated image assets are compressed as WebP to limit package growth.

## Verification

- TypeScript compilation and all nineteen automated tests passed locally.
- The settings workflow and preview update were exercised in the in-app browser.
- Layouts were visually checked at 1440 × 1000 desktop and 390 × 844 mobile sizes.
- Browser console inspection reported no warnings or errors.
- Windows TypeScript, tests, packaging, and PowerShell syntax are verified by CI.

## Known limitations

- First installation still needs a public Discord Application ID.
- Music-to-Discord behavior still requires manual verification in signed-in desktop apps.
- The macOS ZIP is unsigned and not notarized; first launch may require **Right-click → Open**.

## Upgrade notes

Replace the previous extracted folder and rerun the installer. Existing configuration values are preserved.
