# Apple Music Discord Presence v0.4.5

AM Presence now has one unmistakable product mark everywhere, and the setup timeline once again reads as a complete three-step journey.

## Highlights

- One three-bar AM Presence logo across the landing page, settings screen, footer, and browser tab.
- A full-width desktop setup timeline that continues past step 3.
- A continuous vertical setup timeline on tablet and mobile.
- Official Apple and Discord marks in the final service lockup.

## Downloads

| Platform | Download | Requirements |
| --- | --- | --- |
| macOS | `apple-music-discord-presence-macos-arm64.zip` | Apple Silicon, macOS 13+ |
| Windows | `apple-music-discord-presence-windows-x64.zip` | Windows 10 1809+ or Windows 11, x64 |

Extract the ZIP, keep the folder somewhere permanent, and run `Install.command` on macOS or `Install.cmd` on Windows.

## What changed

### Improved

- Replaced the former pink music-note header treatment with the same dark three-bar mark used by the favicon.
- Matched the landing-page header, footer, and local settings header to the `AM Presence` name and mark.
- Replaced the CTA's custom music-note tile with the official Apple silhouette beside the official Discord symbol.
- Extended the desktop setup line through the complete section width, while retaining the vertical mobile layout.
- Versioned the website and settings stylesheets to prevent stale cached branding from surviving an update.

## Verification

- macOS build, Swift helper, TypeScript, and automated tests.
- Manual Browser/IAB checks at 1440 × 1000, 1280 × 820, and 390 × 844.
- Verified the landing-page header, settings header, desktop and mobile setup timelines, horizontal overflow, and stylesheet cache refresh.

## Known limitations

- The macOS build is not signed or notarized, so the first launch may require **Right-click → Open**.
- End-to-end playback still requires Apple Music and desktop Discord running on the user's computer.

## Upgrade notes

No migration required.
