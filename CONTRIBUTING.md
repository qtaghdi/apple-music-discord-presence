# Contributing

Thanks for improving Apple Music Discord Presence.

## Before opening a pull request

1. Use an Apple Silicon Mac with Node.js 20+ and the Xcode Command Line Tools.
2. Install dependencies with `npm install`.
3. Make a focused change and include tests where practical.
4. Run `npm run verify`.
5. If behavior involving Music or Discord changed, manually test with both desktop apps running and note the result in the pull request.

Please do not include personal configuration, Discord secrets, compiled output, logs, or copied code from another project. Bug reports should include the macOS, Node.js, Music, and Discord versions along with relevant log messages, but must omit private account data.
